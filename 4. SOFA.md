# Introduction to SOFA (Skywater Opensource FPGAs)
<img width="1298" height="944" alt="image" src="https://github.com/user-attachments/assets/afa3ed74-3800-4b96-af43-255ade5fb47c" />


SOFA (Skywater Opensource FPGAs) is a collection of open-source FPGA IPs built using the SkyWater 130nm Process Design Kit (PDK) and the OpenFPGA framework. The project aims to provide fabrication-ready FPGA architectures that can be integrated into ASIC and SoC designs while maintaining a fully open-source development flow.

---

# Features
### Architecture Description Files
- Detailed FPGA architecture specifications.
- Compatible with the VTR (Verilog-to-Routing) framework for architecture exploration and evaluation.
- Supports design-space exploration through the OpenFPGA toolchain.

### Fabrication-Ready GDSII Layouts
- Complete physical layouts available in GDSII format.
- Ready for integration into custom chip designs and tape-out flows.
- Based on the open-source SkyWater 130nm technology.

### Post-Layout Verilog Netlists
- Gate-level and post-layout netlists provided.
- Enables HDL simulation and functional verification.
- Supports validation of FPGA-based applications before fabrication.

### Benchmark Suites
- Example benchmark designs included.
- Allows quick evaluation of FPGA architectures and performance.
- Useful for testing synthesis, placement, routing, and timing flows.

### Documentation
- Comprehensive datasheets for each FPGA IP.
- Includes architecture, implementation details, and circuit-level information.
- Supports both research and industrial prototyping activities.

## SOFA FPGA Ecosystem

The SOFA project provides a complete open-source FPGA development platform consisting of:

- FPGA architecture descriptions
- OpenFPGA integration
- Fabrication-ready layouts
- Verilog netlists for simulation
- Benchmark applications
- Detailed technical documentation

# Overview

This repository presents an overview and comparison of High-Density embedded FPGAs (HD eFPGAs). These are specialized FPGA architectures implemented using the Skywater 130nm High Density Standard Cell Library (Sky130_fd_SC_HD).

## What is an HD eFPGA?

High-Density embedded FPGAs (HD eFPGAs) are FPGA fabrics integrated into ASIC-style flows, designed to provide configurable digital logic within standard cell technology.

They are optimized for:
- Area efficiency
- Configurable logic density
- Embedded system integration

## FPGA Architectures Compared

This work compares three HD eFPGA architectures:

### SOFA HD
A baseline high-density FPGA architecture.

Key Features:
- 1152 Look-Up Tables (LUTs)
- 2304 Flip-Flops
- Standard routing structure
- Balanced general-purpose design

### QLSOFA HD
An enhanced version of SOFA HD with improved arithmetic and routing capabilities.

Key Features:
- 1152 LUTs (same logic capacity as baseline)
- 1152 Soft Adders (for arithmetic operations)
- Routing channel width increased to 60
- Improved support for arithmetic-intensive workloads

### SOFA CHD
A configurable high-density variant optimized for flexibility.

Key Features:
- Same logic capacity as QLSOFA HD
- Includes Soft Adders
- Wider routing channels
- Optimized for configurable logic density and adaptability

## Performance Summary

All three architectures operate at a maximum configuration speed of 50 MHz, indicating comparable performance ceilings. The differences lie in internal resource allocation rather than speed.

## Key Comparison

| Architecture | LUTs | Flip-Flops | Soft Adders | Routing Width | Focus |
|--------------|------|------------|-------------|---------------|-------|
| SOFA HD      | 1152 | 2304       | No          | Baseline      | General-purpose |
| QLSOFA HD    | 1152 | 2304       | 1152        | 60            | Arithmetic-heavy |
| SOFA CHD     | 1152 | 2304       | Yes         | Wide          | Configurable density |

## Conclusion

HD eFPGAs demonstrate how FPGA architectures can be tuned by adjusting:

- Logic density (LUTs and Flip-Flops)
- Routing resources
- Arithmetic support (Soft Adders)

This enables different design trade-offs:
- Compact logic design (SOFA HD)
- Arithmetic efficiency (QLSOFA HD)
- Flexible configurable systems (SOFA CHD)
