# SOFA Architecture
## Overview

This experiment focuses on understanding the SOFA (SkyWater Open-Source FPGA Architecture) framework and implementing a simple digital design on a custom FPGA fabric using the OpenFPGA toolchain.

The objective is to study the complete FPGA implementation flow starting from RTL design to architecture mapping, placement, routing, and analysis of post-implementation reports such as area, timing, and power.

A 4-bit counter is used as the reference design to evaluate the behavior of the SOFA FPGA fabric.

SOFA (SkyWater Open-Source FPGA Architecture) is a family of open-source FPGA fabrics developed using the SkyWater 130nm Process Design Kit (PDK) and the OpenFPGA framework.

Unlike commercial FPGA platforms, SOFA provides complete visibility into the FPGA architecture, enabling researchers and designers to study and customize every stage of the FPGA implementation flow.

The SOFA framework combines:

- OpenFPGA for FPGA fabric generation
- VTR (Verilog-to-Routing) CAD flow
- SkyWater 130nm technology library
- Open-source EDA tools

This makes SOFA an excellent platform for FPGA architecture research and experimentation.

# 2. Target FPGA Architecture

The target architecture used in this experiment is:

```text
FPGA1212_QLSOFA_HD_PNR
```

This architecture is a 12×12 tile-based FPGA fabric generated using OpenFPGA and mapped to the SkyWater 130nm technology node.

## Architecture Specifications

| Parameter | Value |
|------------|---------|
| Technology Node | SkyWater 130nm |
| Fabric Type | SOFA FPGA |
| Grid Size | 12 × 12 |
| Logic Blocks | 1152 LUTs |
| Flip-Flops | 2304 |
| Soft Adders | 1152 |
| Maximum Frequency | 50 MHz |

This repository presents an overview and comparison of High-Density embedded FPGAs (HD eFPGAs). These are specialized FPGA architectures implemented using the Skywater 130nm High Density Standard Cell Library (Sky130_fd_SC_HD).

## 7.1 What is an HD eFPGA?

High-Density embedded FPGAs (HD eFPGAs) are FPGA fabrics integrated into ASIC-style flows, designed to provide configurable digital logic within standard cell technology.

They are optimized for:
- Area efficiency
- Configurable logic density
- Embedded system integration

## 7.2 FPGA Architectures Compared

This work compares three HD eFPGA architectures:

### 7.2.1 SOFA HD
A baseline high-density FPGA architecture.

Key Features:
- 1152 Look-Up Tables (LUTs)
- 2304 Flip-Flops
- Standard routing structure
- Balanced general-purpose design

### 7.2.2 QLSOFA HD
An enhanced version of SOFA HD with improved arithmetic and routing capabilities.

Key Features:
- 1152 LUTs (same logic capacity as baseline)
- 1152 Soft Adders (for arithmetic operations)
- Routing channel width increased to 60
- Improved support for arithmetic-intensive workloads

### 7.2.3 SOFA CHD
A configurable high-density variant optimized for flexibility.

Key Features:
- Same logic capacity as QLSOFA HD
- Includes Soft Adders
- Wider routing channels
- Optimized for configurable logic density and adaptability

---

## 7.3 Performance Summary

All three architectures operate at a maximum configuration speed of 50 MHz, indicating comparable performance ceilings. The differences lie in internal resource allocation rather than speed.

## 7.4 Key Comparison

| Architecture | LUTs | Flip-Flops | Soft Adders | Routing Width | Focus |
|--------------|------|------------|-------------|---------------|-------|
| SOFA HD      | 1152 | 2304       | No          | Baseline      | General-purpose |
| QLSOFA HD    | 1152 | 2304       | 1152        | 60            | Arithmetic-heavy |
| SOFA CHD     | 1152 | 2304       | Yes         | Wide          | Configurable density |

---

## Conclusion

HD eFPGAs demonstrate how FPGA architectures can be tuned by adjusting:

- Logic density (LUTs and Flip-Flops)
- Routing resources
- Arithmetic support (Soft Adders)

This enables different design trade-offs:
- Compact logic design (SOFA HD)
- Arithmetic efficiency (QLSOFA HD)
- Flexible configurable systems (SOFA CHD)
