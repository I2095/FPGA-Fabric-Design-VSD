Configured using HDL
Common resources in FPGA

# Difference Between ASIC and FPGA

| Feature | ASIC (Application-Specific Integrated Circuit) | FPGA (Field Programmable Gate Array) |
|--------|-----------------------------------------------|---------------------------------------|
| **Definition** | A custom-designed chip built for a specific application. | A reconfigurable chip that can be programmed after manufacturing. |
| **Flexibility** | Not reprogrammable once manufactured. | Can be reprogrammed. |
| **Performance** | Very high performance due to custom hardware design. | Slightly lower performance compared to ASIC due to programmable structure. |
| **Power Consumption** | Low power consumption (highly optimized design). | Higher power consumption than ASIC. |
| **Cost (Initial)** | Very high (mask design and fabrication cost). | Low to medium (no fabrication required). |
| **Cost (Per Unit)** | Very low in mass production. | Higher per unit compared to ASIC. |
| **Development Time** | Long (months to years). | Short (hours to weeks). |
| **Time to Market** | Slow due to fabrication process. | Fast since no manufacturing is required. |
| **Upgradability** | Not possible after fabrication. | Easily upgradable by reprogramming. |
| **Design Complexity** | Very high (requires full custom design flow). | Easier (uses HDL like Verilog/VHDL and tools). |
| **Best Use Cases** | High-volume products (smartphones, processors, crypto chips). | Prototyping, DSP, AI acceleration, embedded systems, low-to-medium volume designs. |

A Field-Programmable Gate Array (FPGA) is a reconfigurable integrated circuit that allows users to implement custom digital circuits after manufacturing. Its architecture is built from three primary types of resources:

---
## 1. Logic Elements (Configurable Logic Blocks)
Logic elements are the core computational units of an FPGA.
- Arranged in a two-dimensional grid (rows and columns) across the chip.
- Each logic element can implement:
  - Combinational logic (AND, OR, XOR, etc.)
  - Sequential logic (flip-flops, registers)
- In modern FPGAs, these are implemented as **Configurable Logic Blocks (CLBs)** containing:
  - Lookup Tables (LUTs)
  - Flip-flops
---
## 2. Input/Output (I/O) Blocks
I/O blocks provide the interface between the FPGA internal logic and the external world.
- Located around the periphery of the FPGA chip.
- Connected directly to package pins.
- Support multiple voltage standards and signaling modes.
- Can be configured as:
  - Input
  - Output
  - Bidirectional

---
## 3. Interconnection Network (Routing Fabric)
The interconnection system provides programmable communication between logic blocks and I/O blocks.
- Composed of routing wires and programmable switches.
- Organized into:
  - Horizontal routing channels
  - Vertical routing channels
- Enables flexible signal routing across the FPGA fabric.

# Look Up Table (LUT)
LUT for 2:1 MUX

A Look-Up Table (LUT) in an FPGA is a combinational logic element that implements Boolean functions by storing precomputed output values in memory. A common implementation of a 3-input LUT uses a hierarchy of 2:1 multiplexers (MUXes) controlled by input signals.

---
## 1. Basic Principle of Operation
A 2:1 multiplexer selects one of two inputs based on a control signal:
- If S = 0 → Output = A  
- If S = 1 → Output = B  
A LUT extends this idea by using multiple MUX stages to select a value from a stored truth table.
---
## 2. LUT Structure
A 3-input LUT consists of:
- 8 SRAM memory cells storing the truth table outputs  
- A tree of 2:1 multiplexers for selection  
- Three input signals (B, A, S) used as selection inputs  
The stored truth table is represented as an 8-bit configuration vector:
**Z = 0, 0, 1, 1, 0, 1, 0, 1**
These values are programmed during FPGA configuration and remain fixed during operation.
---
## 3. Working Mechanism
During runtime, the LUT behaves like a memory-based function evaluator:
- Inputs (B, A, S) act as an address to the stored memory  
- The MUX tree selects one of the 8 stored bits  
- Each stage reduces the selection space:
  - Stage 1 → controlled by B  
  - Stage 2 → controlled by A  
  - Stage 3 → controlled by S  
This ensures that exactly one stored value reaches the output.
---
## 4. Example Evaluation
Consider:
- S = 1, A = 0, B = 1  
From the truth table: Z = 1
### Step-by-step:
- Stage 1 (B = 1): selects relevant memory subset  
- Stage 2 (A = 0): narrows selection further  
- Stage 3 (S = 1): selects final stored bit  
Final Output: Z = 1
---
## 5. Key Insight
A LUT does not compute logic using gates in real time. Instead, it:
- Stores all possible output values in memory  
- Uses a MUX tree as an address decoder  
- Retrieves the correct output based on input selection
