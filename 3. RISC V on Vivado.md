## Objective
This project demonstrates the implementation of a RISC-V based processor core on an FPGA using the Vivado Design Suite. The design includes RTL implementation, synthesis, simulation, and hardware validation using a testbench.

---
## About RISC-V on FPGA

RISC-V is an open-source Instruction Set Architecture (ISA) widely used for embedded and FPGA-based processor design. Implementing a RISC-V core on FPGA allows:
- Hardware-software co-design learning
- Custom processor architecture exploration
- Understanding CPU pipeline behavior
- Real hardware execution of custom instructions
---

## FPGA Design Flow
1. RTL Design (Verilog)
   - Design of processor core and modules
2. Functional Simulation
   - Verify logic using a testbench
3. Synthesis (Vivado)
   - Convert RTL into gate-level netlist
4. Implementation
   - Place and route on FPGA fabric
5. Bitstream Generation
   - Create `.bit` file for FPGA programming
6. Hardware Testing (optional)
   - Run design on FPGA board and verify outputs

# Description

- **RISC-V Core**: Main processing unit executing instructions
- **Program Counter (PC)**: Tracks instruction sequence
- **ALU**: Performs arithmetic and logical operations
- **Register File**: Stores temporary data and operands
- **Instruction Decode**: Decodes incoming instructions
- **Data Memory Interface**: Handles memory read/write operations
- **ILA Core**: Captures internal signals for real-time debugging
- **Vivado Hardware Manager**: Used to view captured FPGA signals

# Testbench for Core Module
This is a simple Verilog testbench for the `core` module. It generates a clock, applies reset, and runs the simulation for a fixed duration.

---
## Testbench Code
```verilog
module test();
reg clk, reset;
wire [7:0] out;
core uut (clk, reset, out);
initial begin
    clk = 1'b0;
    reset = 1'b0;
    #10;
    reset = 1'b1;
    #50;
    reset = 1'b0;
end
// Clock generation (10 time unit period)
always #5 clk = ~clk;
// Stop simulation after 200 time units
initial #200 $finish;
endmodule
```
## Testbench Overview
The testbench is used to verify the functionality of the `core` module.
### Working:
- Clock signal toggles every 5 time units
- Reset is asserted after 10 time units
- Reset is deasserted after 60 time units
- Simulation runs for 200 time units
### Purpose:
To ensure correct initialization and basic operation of the RISC-V core design.

## Integrated Logic Analyzer (ILA) Debugging
An Integrated Logic Analyzer (ILA) core from Vivado has been added to the design for real-time signal debugging on FPGA hardware.

### Purpose of ILA
The ILA is used to observe internal signals of the RISC-V core during runtime, which cannot be directly seen on output pins. It helps in:
- Monitoring internal CPU signals in real-time
- Debugging instruction execution flow
- Verifying register and memory updates
- Checking control and datapath behavior on FPGA hardware

### Signals Monitored
Typical signals connected to the ILA include:
- Clock (`clk`)
- Reset (`reset`)
- ALU output

### Workflow

1. Insert ILA IP core in Vivado Block Design or RTL
2. Connect required internal signals to ILA probes
3. Generate bitstream and program FPGA
4. Open Vivado Hardware Manager
5. Capture and analyze signals in real-time

### Benefit

Using ILA eliminates the need to rely only on simulation and allows debugging directly on hardware, making it extremely useful for validating the RISC-V processor behavior on FPGA.

## Summary
This project implements a basic RISC-V processor core using Verilog HDL and verifies its functionality through simulation. The design is developed in a modular way and tested using a simple testbench that generates clock and reset signals. The simulation helps confirm correct initialization and basic operation of the core.

The project follows a standard FPGA design flow, including RTL design, functional simulation, synthesis using Vivado, and (optionally) hardware implementation on an FPGA board. Tools like Vivado and waveform viewers are used to analyze and validate the design behavior.

Overall, this project provides hands-on understanding of RISC-V processor architecture, digital design concepts, and FPGA-based system development.
